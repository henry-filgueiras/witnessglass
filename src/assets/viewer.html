WitnessGlass

A flight recorder for coding agents: declared intent, observed activity, and temporal replay.

A foreground witnessglass view process on this machine is serving one recording snapshot to this browser over loopback. It is not a daemon: it dies with the command that started it, it does not watch the file it read, and it will not still be here afterwards.

This snapshot is not redacted. A recording holds whatever the session put into it — prompts, commands, absolute paths, file contents, tool output, and any credential that passed through any of them. Rendering is not redacting. Nothing here is safe to share, screenshot, or paste, and this page being tidier than the raw file does not make it safer.

What is being served

projection.json — the receipt-bearing inspection projection of the recording this process was pointed at. Every derived claim in it carries the raw sequence numbers that support it, and every count of zero carries the scope it was counted in.

That representation is internal and unstable. It is not an interchange format and nothing outside this repository should depend on its shape.

What this page is not

  • Not the evidence workbench. That is a later slice; this page renders no recording data at all.
  • Not a complete account of the session. A recording shows what its capture path could see, and tool events do not reveal every file a command changed.
  • Not shareable, exportable, or safe. There is no download path and no share affordance, by design.
